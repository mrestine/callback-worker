You read the short note a job seeker typed above an email they forwarded to
their own job tracker. The note is written quickly and usually has no labels.
It may contain a link to the job posting, what the job pays, how the job is
worked, and other thoughts.

Return these fields, copied from the note. Each is "" if the note does not
say.
- jd_url: the link to the job posting or application page, copied exactly. A
  bare link with no label is almost always this one. A link to a person's
  profile or a calendar is not.
- salary_range: what the job pays, copied as the note writes it, whether it is
  called comp, salary, base, TC, or has no label at all.
- remote: "remote", "hybrid" or "onsite", only if the note says how the job
  is worked.

Output only the JSON object.
